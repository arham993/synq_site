# SYNQ, IQ Suites by Highlife

Launch site for SYNQ, fully furnished 1 & 2 BHK AI smart homes in a G+18 tower, Greater Noida West.

- Single static page: `index.html` with images in `img/`
- 3D tower built with Three.js, scroll animation with GSAP ScrollTrigger and Lenis (all loaded from CDN)
- The enquiry form opens WhatsApp with the buyer's details filled in. Change the number in `WHATSAPP_NUMBER` inside `index.html`.

Hosted on GitHub Pages from the `main` branch root.
