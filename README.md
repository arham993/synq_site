# SYNQ, IQ Suites by Highlife

Launch site for SYNQ, fully furnished 1 & 2 BHK AI smart homes in a G+18 tower, Greater Noida West.

- Single static page: `index.html` with images in `img/`
- Photo-based scroll animation with GSAP ScrollTrigger and Lenis (loaded from CDN)
- The enquiry form opens WhatsApp with the buyer's details filled in. Change the number in `WHATSAPP_NUMBER` inside `index.html` (currently +91 99994 34837).

Hosted on GitHub Pages from the `main` branch root.
